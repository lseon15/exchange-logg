# 환전 기록

환전한 외화(유로·영국 파운드·일본 엔·미국 달러)의 누적 보유량과 **평균 매수 환율**을 기록하고,
실시간 환율과 비교해 손익(± %, ± 원)을 확인하는 모바일 웹앱입니다. 모든 기록은 기기에 저장됩니다.

---

## 1. GitHub에 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `exchange-record`
2. 이 폴더의 파일 전체를 저장소에 업로드합니다.
   - `index.html`, `manifest.json`, `sw.js`, `README.md`, `icons/` 폴더(아이콘 3개)
3. 저장소 → **Settings → Pages** 로 이동합니다.
4. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/(root)` 으로 설정하고 **Save**.
5. 1~2분 뒤 주소가 생성됩니다. 예: `https://사용자이름.github.io/exchange-record/`

> ⚠️ 반드시 `github.io` 주소(HTTPS)로 접속해야 앱 설치와 오프라인 기능이 동작합니다.

## 2. Chrome에 앱으로 설치하기

**PC (Chrome)**
1. 위 주소를 Chrome 주소창에 입력해 접속합니다.
2. 주소창 오른쪽의 **설치 아이콘(⤓ / 모니터 모양)** 을 클릭하거나,
   우측 상단 ⋮ 메뉴 → **캐스트, 저장 및 공유 → 페이지를 앱으로 설치** 를 선택합니다.
3. 독립 창으로 실행되는 "환전 기록" 앱이 설치됩니다.

**Android (Chrome)**
1. 주소로 접속 → ⋮ 메뉴 → **홈 화면에 추가 / 앱 설치** 를 선택합니다.
2. 홈 화면에 아이콘이 생기고, 일반 앱처럼 실행됩니다.

**iPhone (Safari)**
1. Safari로 접속 → 공유 버튼 → **홈 화면에 추가**.

## 3. 사용

- 통화를 선택하고 **환전 금액**과 **적용 환율**을 입력한 뒤 `기록 추가`.
- 통화 카드를 누르면 건별 상세 기록이 펼쳐지고, `✕` 로 개별 삭제할 수 있습니다.
- `실시간 환율 자동 불러오기` 로 시장 환율을 가져오거나, 각 칸에 직접 입력해 내 평균 환율과 비교합니다.

> 실시간 자동값은 유럽중앙은행 기준 **시장 중간환율**로, 은행 고시환율(스프레드 포함)과는 차이가 있습니다.
> 데이터 출처: frankfurter.app (실패 시 open.er-api.com 보조).

## 설치가 "바로가기"로만 될 때 (앱으로 설치가 안 될 때)

모바일 Chrome은 아래 조건을 **모두** 통과할 때만 "앱 설치"(별도 앱 등록)를 띄웁니다.
하나라도 어긋나면 "홈 화면에 추가 = 바로가기(북마크)"로만 등록됩니다.

1. **HTTPS 주소로 접속했는가** — 반드시 `아이디.github.io/저장소이름/` 형태여야 합니다.
   `raw.githubusercontent.com/...` 주소나 파일 다운로드 링크로 열면 안 됩니다.
2. **`icons/` 폴더가 저장소에 올라갔는가** — 아이콘 파일 3개(192·512·maskable)가 모두 있어야 합니다.
   주소창에 `.../저장소이름/icons/icon-192.png` 를 직접 입력했을 때 아이콘이 보여야 정상입니다. (안 보이면 업로드 누락)
3. **`manifest.json`, `sw.js` 가 루트에 있는가** — index.html과 같은 위치여야 합니다.
4. 앱을 열면 상단에 **"⤓ 앱 설치" 버튼**이 뜹니다. 이 버튼을 누르면 곧바로 설치창이 나옵니다.
   **버튼이 안 보이면** 위 1~3 중 무언가가 아직 안 맞는 것입니다.

빠른 점검: PC Chrome에서 배포 주소 접속 → F12(개발자도구) → **Application 탭 → Manifest / Service Workers**
에서 오류가 없는지 보면 원인을 바로 알 수 있습니다.

## 데이터 저장

기록은 브라우저(설치한 앱)의 로컬 저장소에 남습니다. 같은 기기·같은 앱에서는 유지되지만,
브라우저 데이터를 지우거나 다른 기기로 옮기면 기록은 이동되지 않습니다.
